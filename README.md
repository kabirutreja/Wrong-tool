## 3D html game
HALL is a first person shooter built using only HTML and CSS, with no JavaScript. The 3D hall, with its stairs, pillars and animated guards, is made from CSS 3D transforms. All the game logic runs on hidden radio buttons and checkboxes, selected with :checked, :actives.

* How it works:

Movement and turning: W/A/S/D or the on-screen buttons move you through the hall. Q and E turn you in 90° steps, and a compass shows which way you’re facing.

Shooting: click a guard to shoot them, with a muzzle flash and gun recoil. Each guard is a checkbox.

Win and lose: shoot all five guards in 75sec to win. A CSS counter tracks kills.

Atmosphere: flickering lamps, a torch mode that dims the hall, stairs you can glide up and down, a main menu, and a red alarm that pulses in the last 10 seconds.


Controls: W/A/S/D to move, Q/E to turn, F to fire, R for stairs, L for torch mode, and click guards to shoot and touch controls (Keyboard controld don't work right now).

## Skybound

Skybound is a small adventure game made using HTML and CSS. Explore floating islands, collect the hidden crystal, and unlock the portal to reach the next level. In the Ancient Ruins, explore the area, collect the relic, and reach the exit to complete the game. Choose your paths carefully and see if you can make it to the end!

## Tic-Tac-Toe

Tic-Tac-Toe Ultimate is a small web game I built using HTML, CSS and JavaScript. It started with the classic tic-tac-toe idea, but I wanted to add a few extra features to make it more fun to play.

You can play against the computer on three difficulty levels: Easy, Medium and Unbeatable. The game also keeps track of your matches, shows your stats, and has achievements and an XP system where you earn points and level up as you play.

I added sound effects and a few animations too, along with a custom Forest Arcade design using dark green, cream and orange colours. Your progress is saved in the browser, so your stats and unlocked achievements can stay there between visits.

This project was a way for me to practise JavaScript, work with the DOM, learn about game logic and build something with more features than a basic tic-tac-toe game. There are still things I can improve, but I'm happy with how it's coming together.

## Shards clicker

Shards clicker is a game built in google sheets using apps scripts. It's a regular clicker game with a twist. Score more, unlock workers, powerups and rank on the leaderboard.
